# Contribuindo

Obrigado por contribuir com o `fast-drawio`.

## Fluxo

1. Crie uma branch a partir de `main` usando um nome claro, como `feat/nome-do-diagrama`, `fix/ajuste-de-layout` ou `docs/melhoria`.
2. Faça uma alteração pequena e focada. Não mova nem apague arquivos existentes sem necessidade documentada.
3. Abra e revise os arquivos `.drawio` no [app.diagrams.net](https://app.diagrams.net/).
4. Faça um commit com mensagem objetiva em português.
5. Envie a branch e abra um pull request descrevendo o objetivo, os arquivos afetados e a validação realizada.

## Validação antes do envio

- Confirme que o arquivo `.drawio` abre sem erro no app.diagrams.net.
- Verifique visualmente alinhamento, conexões, textos e legibilidade.
- Confirme que não foram incluídos arquivos temporários do macOS ou do editor.
- Revise `git status` e o diff para garantir que apenas as mudanças esperadas serão enviadas.
- Atualize a documentação quando a alteração introduzir uma nova convenção ou tipo de diagrama.
